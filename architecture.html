Estima — architecture

Estima est une application Next.js hébergée sur Vercel. Le navigateur charge la page d'accueil et appelle des routes API (propriétés, estimations, import DVF admin) exécutées côté serveur. Ces routes lisent et écrivent dans une base PostgreSQL via Prisma, avec trois modèles : Property, Valuation et DvfTransactionCache.
